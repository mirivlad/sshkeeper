# sshkeeper v0.8.4 — copy from SSH tabs and close completed sessions

## Improved

- **Text selection without Shift.** Left-button drag in an embedded SSH tab
  highlights text and copies it to the system clipboard on release. Selection
  supports Unicode, multiple lines and the scrollback viewport. Native clipboard
  support is used where available; terminal OSC 52 is a fallback.
- **Successful SSH exit closes its tab.** Clean remote shell exit (status 0)
  removes the workspace tab automatically. If that tab was in the background,
  focus stays on the current workspace. The last tab returns to Servers.
- **Failures remain inspectable.** Nonzero SSH exit status or connection errors
  retain the terminal output and error in the tab until manually closed.
- **No regression to navigation.** The terminal mouse wheel still scrolls output,
  and clicking the tab strip still switches tabs.

Automated regression tests cover text selection, scrollback, Unicode, clean
exits and failed SSH processes. Normal tmux-backed persistent sessions remain
independent from the embedded PTY/ConPTY workspace.
