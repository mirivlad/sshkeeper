# sshkeeper v0.8.3 — terminal scrollback and visible cursor

v0.8.3 fixes two terminal-compatibility gaps in the embedded Session Workspace.

## Fixed

- **SSH output scrollback.** The workspace now exposes x/vt's real main-screen
  scrollback buffer. Mouse wheel and `PgUp` / `PgDn` move through previous
  shell output, including long commands such as `cat`.
- **Typing returns to live output.** Sending keyboard input or pasted text snaps
  a scrolled shell tab back to the live terminal.
- **Stable scrollback while output continues.** If new lines arrive while the
  user is reading history, the viewport stays anchored instead of jumping
  toward the newest output.
- **Visible remote cursor.** The renderer now overlays the cursor tracked by the
  VT emulator, fixing editors and other full-screen programs where the text
  cursor was previously invisible.
- **Alternate-screen applications keep their keys.** Local scrollback is
  disabled while programs such as `nano`, `vim`, or `mc` own the alternate
  screen, so their `PgUp` / `PgDn` behavior is not intercepted.
- **Help and documentation updated** with scrollback controls.

The event-driven redraw model from v0.8.2 remains unchanged; idle sessions still
do not poll or redraw continuously.
