# sshkeeper v0.8.7 — native terminal selection in SSH tabs

## Improved terminal experience

- SSH tabs now leave mouse selection to the **outer terminal**. Select text normally and press its `Ctrl+Shift+C` to copy; merely highlighting text never overwrites the clipboard.
- `Ctrl+Shift+V` (and `Shift+Insert`, where configured) pastes through the terminal's standard bracketed-paste mechanism.
- SSHKeeper reserves only its tab controls: `Alt+1`–`Alt+9` jump to SSH tabs, `Alt+0` returns to Servers, `Alt+Left` / `Alt+Right` switch tabs, and `Alt+W` closes the active tab and SSH session.
- `Ctrl+C` and other unrelated shortcuts stay available to remote shells and programs. `Ctrl+PgUp` / `Ctrl+PgDn` are no longer stolen for SSHKeeper tab switching.
- Mouse controls return automatically in the Servers dashboard. Help and documentation have been updated.

## Notes for testing

- In an SSH tab, selection and clipboard shortcuts follow your terminal emulator's settings; in particular, `Ctrl+Shift+C` may be remapped by your terminal.
- Use the `Alt` tab shortcuts rather than mouse clicks on SSHKeeper's tab bar while an SSH tab is focused.
- SSHKeeper uses an alternate screen and its own SSH output history. For long shell output, try `PgUp` / `PgDn`; wheel scrolling through history may vary by terminal emulator.
- Remote applications requesting their own mouse tracking (for example, Vim with `mouse=a`) do not yet receive forwarded mouse reports. Keyboard editing is unaffected.

This patch does not change stored SSH profiles or vault data.
