# sshkeeper v0.7.1 — password logins on Windows

v0.7.1 makes the experimental Windows build usable for every profile type.

## Fixed

- **Start from Explorer.** Double-clicking `sshkeeper.exe` no longer stops
  with "run it from cmd.exe"; the TUI opens in its own console window. If
  startup fails there, the window waits for Enter so the error stays readable.
- **Password and key-passphrase auth on Windows.** These profiles used to fail
  with "not supported on Windows". sshkeeper now runs `ssh.exe` in a Windows
  pseudo console (ConPTY) and types the stored secret at its prompt, as it
  does on Linux and macOS. Connect, connection test, and running commands all
  work; full-screen programs and window resizing work inside the session.

Windows needs Windows 10 1809 or later and OpenSSH Client as `ssh.exe` in
`PATH`. Background tunnels still accept only key or agent auth, on every
platform.

To install on Debian/Ubuntu x86-64, download the release asset and run
`sudo apt install ./sshkeeper_0.7.1-1_amd64.deb` (use the arm64 package on ARM64).
