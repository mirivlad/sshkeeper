# sshkeeper v0.8.8 — reliable SSH scrollback and copying

## Fixed

- Restored SSHKeeper's own mouse handling inside SSH tabs. Mouse wheel now scrolls the internal shell output history instead of unexpectedly navigating previous shell commands.
- Restored drag-to-edge autoscroll so long command output can be selected across multiple screens, including nested SSH sessions.
- Restored double/triple-click text selection and clickable workspace tabs while in scrollback mouse mode.
- Made the previously hidden **[Copy]** action visible in the SSH tab status line.

## How copying works

- **Default scrollback mode:** drag to select, scroll with the wheel, and press **Alt+C** or click **[Copy]** to copy to CLIPBOARD. Selection alone updates PRIMARY where supported, without overwriting CLIPBOARD; middle-click pastes PRIMARY.
- **Alt+M** switches to native terminal selection mode. Then normal drag and **Ctrl+Shift+C** belong to your enclosing terminal (for example XFCE Terminal). In this mode the wheel may scroll shell command history rather than SSHKeeper output.
- **Alt+M** again returns to internal scrollback and mouse selection. `PgUp` / `PgDn` continue to scroll normal shell output; full-screen programs such as `vim`, `nano` and `less` handle their own paging.

## Verification

- Added regression tests for native/scrollback mouse-mode changes, internal wheel scrolling of long nested-SSH-style output, drag autoscroll, explicit clipboard copy, and preservation of remote Ctrl+C / Ctrl+PgUp behavior.
- No changes to SSH profiles, key storage, encrypted vaults, or synchronization.
