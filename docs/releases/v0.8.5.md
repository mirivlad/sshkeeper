# sshkeeper v0.8.5 — terminal-style mouse selection

## Fixed

- **Drag-to-scroll selection.** Holding a mouse selection against the top or
  bottom edge automatically scrolls through SSH output. The selected range can
  extend well beyond the visible terminal rows. Timers run only while dragging
  at an edge and stop when the drag ends.
- **Mouse wheel preserves selection.** Scrollback may be browsed before or
  after releasing the mouse button, without losing the highlighted range.
- **Double-click selects a word.** Unicode letters, digits and underscores
  count as word characters. Dragging extends the range by full words.
- **Triple-click selects a line.** Dragging extends the range by full lines,
  in either direction. Single-character dragging remains unchanged.
- **Usual mouse features retained.** Clickable tabs, scrolling and automatic
  clipboard copy on mouse release still work.

Regression tests cover Unicode, punctuation, word/line drags, selection across
scrollback, repeating edge scrolling, wheel preservation, multi-click timing,
clipboard copy and cancelled timers.
